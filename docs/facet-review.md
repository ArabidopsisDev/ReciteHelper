# cFSRS：规则化复习中的切面调度

研究与实现：2026-11-15；判分和调度修订：2026-11-17。

## 使用过程

原题同时考查“小麦叶斑病的病症与病害循环”时，AI 分别评价这两部分，并依据评分要点给出占比。若病症部分正确、循环部分错误，智能复习使用独立的病害循环题。该题会明确指出需要说明的对象和环节，批改继续直接标在用户答案上。

原题一旦建立切面，就从智能复习题池中移出。题池仍覆盖项目的所有聚类。未完成的切面优先进入复习；已经回答完整的部分保留各自的记忆状态，到期后以对应切面题再次出现。题池补足数量时也会遵守这条规则。原题继续用于章节练习和模拟考试。

答题区显示切面名称和原题占比，悬停可以查看原题与占比依据。切面批改完成后，页面显示原题掌握度的变化。原题上次完整作答的对错状态、答案与批注继续保留。

已有项目可继续打开。尚无切面数据的多问题目，在下一次完整作答被 AI 批改后建立切面。单独练习切面时只评价当前范围，不继续向下拆分。cFSRS 在每个自然内容组件上使用现有 FSRS-6，再组合其掌握度并安排出题。

题干明确分成症状、发病循环、病害特征三问时，作答区和批改结果都保留三问。颜色、部位、越季和侵染阶段等属于各问内部的评分要点。若旧题保存了七八个细碎切面，作答区优先按题干恢复自然分问；下一次完整批改后重新建立对应切面，旧切面及其学习记录保存在 `archived_review_facets`，不再参与抽题。重整前的历史答案仍完整显示，不按新的分问截取。

## 研究依据与选择

1. [FSRS 官方算法说明中的 FSRS-6 部分](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm#fsrs-6)给出了单个记忆项的稳定度、难度、同日更新和遗忘曲线。工程继续使用现有的 21 参数 FSRS-6。
2. [官方 Python 实现](https://github.com/open-spaced-repetition/py-fsrs/blob/main/fsrs/scheduler.py)可用于核对单项状态与预测方式。每个切面分别维护自己的状态和实际考查时间。
3. [Corbett 与 Anderson 的知识追踪研究](https://doi.org/10.1007/BF01099821)以知识组件跟踪学习状态。[Pardos 与 Heffernan 的研究](https://people.csail.mit.edu/zp/papers/pardos_EDM09_final.pdf)进一步讨论了题目机会与组件学习的关系。这些研究支持按考查内容分别保存证据；本实现的组合权重与调度规则在下面单独定义。
4. [SuperMemo 的知识表述原则](https://super-memory.com/articles/20rules.htm)讨论了简单、明确的记忆项及各子项分别安排复习的价值。据此，本次将切面限定为病症、循环等自然分问，不把颜色、形状等一句答案内的细节继续碎片化。
5. [Py-FSRS 的使用说明](https://github.com/open-spaced-repetition/py-fsrs/blob/main/README.md)包含学习和重学的短间隔设置；[Anki 的显示顺序与同源卡片管理](https://docs.ankiweb.net/manual/deck-options)区分到期项与新项，并提供同源卡片的延后机制。本项目据此采用 10 分钟重练等待和原题间穿插。这两个具体策略是 cFSRS 的工程选择。

## 资料和课程评分尺度

有资料时，生成过程从相关内容提取原文摘录，程序核对摘录是否存在于资料。题目和每问的满分参考答案只列本科课程所需的核心要点。批改时将原文、题目范围及核心答案一同提交给模型，接受同义表达和合理简述，不按专家级穷尽程度评分。

设模型观察到每问的核心要点覆盖比例为 `sᵢ`。本次默认门槛为 70%：

```text
gᵢ = 1，       sᵢ >= 0.70 且无 FL
gᵢ = sᵢ，      sᵢ < 0.70 且无 FL
gᵢ = min(sᵢ, nextDown(0.70))，出现 FL
本问通过 = (sᵢ >= 0.70 且无 FL)
整题通过 = 所有自然分问均通过
整题得分 = Σwᵢgᵢ
```

程序保存原始 `sᵢ`，用于说明实际覆盖程度；`gᵢ` 是按当前课程门槛计算的得分。占 80% 的一问答对、占 20% 的一问空白，整题得 80%，仍判为未全部掌握。70% 是课程复习的判定策略，与 FSRS 的 90% 目标保持率分别控制评分和调度。

FL 指关键答案混淆或根本误解，优先于覆盖率；普通遗漏不属于 FL。`nextDown(0.70)` 是小于门槛的相邻浮点数，用来避免关键概念错误被当作掌握，原始覆盖率仍保留。多问现在逐问独立请求 AI 批改，再按既定占比合计；参考答案上方的 AC / PT / WA / FL 状态块展示各问结果。45% 是 PT 的显示边界，不是新的 FSRS 掌握门槛。

## 独立状态与原题占比

新题在生成时写明自然分问及占比，首次建立切面时沿用该结构。旧题沿用已有切面占比；仅有可识别分问而尚无评分占比的旧题，默认等分。每问独立批改时不重新估算占比。评分结构包含正确、错误和未达标的各部分，每部分有稳定标识、名称、独立题干、核心参考答案、得分比例和占比依据。各部分覆盖原题且不重复。

设各部分的原始分值为 `aᵢ`，保存时归一化为：

```text
wᵢ = aᵢ / Σaⱼ
Σwᵢ = 1
```

切面建立后，后续整题批改沿用该结构与占比。切面 `i` 保存自己的稳定度 `Sᵢ`、难度 `Dᵢ`、上次实际考查时间，以及最近一次被观察到的准确比例 `gᵢ`。

FSRS-6 预测其回忆率：

```text
Rᵢ(t) = (1 + F × Δtᵢ / Sᵢ)^(-w₂₀)
F = 0.9^(-1/w₂₀) - 1
```

覆盖不足 70% 使用 `Again`，达到门槛使用 `Good`。`Hard` 表示成功回忆，不用来代替未通过的回答。稳定度和难度继续按现有 FSRS-6 更新，遗忘时间、既有稳定度和难度均参与计算。

原题的两个汇总量分别是：

```text
预计记忆覆盖率 R原题(t) = Σ wᵢ × Rᵢ(t)
原题掌握度     M原题(t) = Σ wᵢ × gᵢ × Rᵢ(t)
```

加权求和按当前评分策略的预期得分解释，不要求各切面完全独立。掌握度使用最近一次的达标得分 `gᵢ`；真实原始覆盖比例另行保存。它们均不等于“整题所有细节一次作答全部正确的概率”。

只练习切面 `k` 时，其他切面的状态和时间不变。因此，同一时刻原题掌握度的变化量满足 `|ΔM| ≤ wₖ`。原题的整题复习次数也不会因此增加。

## 调度次序与组合间隔

刚答错的切面与未拆分的单问等待 10 分钟后进入智能复习。已通过的规则化题目与切面只有在预计回忆率低于目标时进入题池，题量不足时也不会用尚未到期的这些题补齐。

到期的未通过切面优先。相同层级中，使用预计尚未掌握的原题内容占比排序：

```text
缺口ᵢ = wᵢ × (1 - gᵢ × Rᵢ)
```

例如两个切面同样完全遗漏，占原题 80% 的部分会排在占 20% 的部分之前。在这一顺序上，每道原题先安排一个候选，再安排各原题的第二个候选，避免同一原题连续占据短复习任务。各聚类共同参与。

全部切面通过后，原题的组合间隔通过求解下面的方程得到：

```text
Σ wᵢ × R(Δtᵢ + h, Sᵢ) = 目标保持率
```

程序保留各部分已经经过的时间，通过二分求解 `h`。如果当前覆盖率已低于目标，间隔为 0。该方法同时考虑各切面的占比、稳定度和遗忘时间。

仍有未通过切面时，原题的下一次建议复习时间取这些切面的最早可重练时间，避免显示“建议几天后”却存在刚答错的内容。该建议与上面的组合遗忘曲线分别计算。

## 既有证据与参数学习

拆分前，明确记录为完整答对的整题作答可以为所有切面提供成功证据，用于建立初始状态。此前答错的整题记录无法指出具体错在哪一部分，因此不为切面添加失败标签。

参数拟合保留拆分前的整题历史。拆分后的整题记录留作完整作答记录，其训练证据由对应切面提供。训练采用加权交叉熵：

```text
L = Σ vⱼ × BCE(yⱼ, Rⱼ) / Σvⱼ + 原有参数正则项
```

同一次整题作答产生的切面观测使用 `vⱼ = wᵢ`，总权重为 1；一次独立切面作答使用权重 1。继承的整题成功记录只参与切面状态重放，权重为 0，避免再次计入训练损失。个性化参数更新后，会重放所有切面的历史。

模拟考试会保留题目来源标识。即使不同聚类中的数字题号相同，考试副本也能关联回正确原题；批改结果会更新并保存对应切面。

## 验证与范围

测试检查局部抽题、全聚类候选池、原题排除、占比排序、掌握度增量上限、未考查部分状态不变、评分结构、组合曲线、参数学习、保存及考试来源关联。本次补充了门槛、资料、分问、原文批注、并发和到期规则检查，共 131 项测试通过。

真实 DeepSeek 批改样本、实际调用路径的出题耗时和固定延迟实验见 [2026-11-16 实验记录](experiments/cfsrs-2026-11-16.md)。它们验证当前实现和少量评分案例；长期记忆效果仍需真实作答数据评估。

原生 WPF 离线算例使用病症 40%、循环 60% 的评分结构。经过一个学习日后，病症部分的贡献约为 37.9%；完成循环切面后，原题掌握度约为 97.9%，增量为 60 个百分点。该算例验证数值更新和界面流程，线上模型的切面划分与评分质量需要通过实际作答持续检查。新增组合层尚无真实学习数据的对照评测结果。
