# Emotion-LLaMA 与 FSRS 的融合研究方案

研究日期：2026-10-13。研究对象：`D:\Projects\OpenRecite` 当前 SDK。状态：设计与源码核查，未开展受试者实验、未运行 Emotion-LLaMA 推理、未训练融合模型。以下所有阈值、时间安排和融合公式中新增部分均为本项目提案，不是文献已证实的学习效果。

## 1. 已确定的实现方向

采用“FSRS 记忆模型 + 可关闭的情境观测服务 + 受约束的会话策略”三部分。首期 Emotion-LLaMA 只提供学习情境证据，不写入 FSRS 的 grade、S、D 或原有复习历史；FSRS 根据真实作答继续生成到期时间。先回答两个问题：本人的自然复习情境能否被可靠观测；这些观测在行为指标之外是否有增量价值。只有两个问题都有数据支持，才进入独立的记忆模型扩展试验。

部署以个人电脑本地使用为目标。Emotion-LLaMA 作为进程外、可异步运行的研究服务，与 OpenRecite NuGet 主包分开；SDK 不加载 Python、PyTorch、摄像头驱动或 LLaMA 权重。当前机器只有 Intel Iris Xe 与约 15.73 GiB 内存，首期不假设原版模型可以低延迟实时运行。若硬件试验失败，先做本地会话录像的离线批推理；无法完成则保持手动状态标注和行为特征基线，Emotion-LLaMA 分支明确停留在未验证状态。远端 GPU、云上传或新增设备不是默认前提。

“首期接入完成”的含义是可记录、可回放、可关闭和可评估，不是宣称情绪识别提升了学习效果。SM-2、Leitner 等已有调度器保留；情境策略在调度器外工作，便于同一观测协议复用。

## 2. 证据边界

| 判断 | 证据及边界 |
|---|---|
| FSRS 提供按历史作答变化的回忆概率与时间间隔 | 官方 FSRS 公式与本地源码相符；这并不证明额外情绪特征有效。[S1] |
| Emotion-LLaMA 能融合音频、视频、文本做情绪识别与推理 | 原论文及官方仓库支持该能力；报告的评测来自情绪数据集，不是本人的背诵场景，也不是长期记忆效果。[S2][S3] |
| 表情不能直接等同于内部情绪 | 表情到情绪的反推有情境依赖；视频预测在此只能作为不确定证据。[S4] |
| 困惑未必有害 | 在复杂学习任务中，经调节与解决的困惑可伴随学习收益；不能据此认定背诵中所有困惑都有益，或一见困惑就降低难度。[S5] |
| 机器学习可与记忆模型结合 | HLR 展示了可训练记忆模型与特征结合，未检验 Emotion-LLaMA + FSRS。[S6] |
| 正确的预测评估应按时间切分 | 上游 SRS benchmark 使用时序评估并同时报告概率损失、区分度及分箱误差。本地实验冻结 FSRS-6，不把上游现有 FSRS-7 表格当作本地性能。[S7] |
| 置信度需要校准；可拒绝输出 | 神经网络校准与 selective classification 文献支持该原则；不能直接把文字中的“很确定”或 token 概率当情绪正确率。[S8][S9] |
| 重复随机化适合探索短期干预 | MRT 文献提供设计和功效分析框架；通常依赖多人重复观测，单人使用要另行处理序列相关和可推广性。[S10][S11] |

目前没有在本轮检索的一手资料中找到“原版 Emotion-LLaMA 与 FSRS 的融合已被证明提升延迟记忆”的证据。该组合属于待验证的集成与研究假设。

## 3. 本地代码约束与先决条件

本轮直接读取了以下文件：

- `src/OpenRecite/Core/Scheduling/FsrsAlgorithm.cs`：纯函数 FSRS-6，21 参数模型的回忆曲线、初始状态、跨日与同日状态更新。
- `src/OpenRecite/Core/Scheduling/FsrsDualModel.cs`：与基础模型对应的自动微分实现。
- `src/OpenRecite/Core/Scheduling/FsrsOptimizer.cs`：从 `ReviewTag` 取 Grade，缺失时回退旧 QValue；所有合法历史参与状态推进，只对间隔至少一天的后续复习计概率损失。
- `src/OpenRecite/Application/Services/FsrsReviewScheduler.cs`：`Record` 更新 Memory，但不负责追加完整历史事件。
- `src/OpenRecite/Application/Services/ReviewPersonalizationService.cs`：用同一拟合数据上的损失改善决定参数更新；这不是独立验证集证明。

结合主研究中的代码审计：`QuizService` 目前把二值正确性映射为 Again/Good 并追加 `ReviewTag`。因此初期真实 grade 仍以现有二值口径为准；不能假装历史中有用户亲自提供的 Hard/Easy，也不能用情绪合成这两档。若后续增加显式四档评分，必须记录评分来源和协议版本，将前后时期分开检查。

未来实验实现前必须完成四项数据约束：

1. 明确唯一 `ReviewEventId` 和原子写入边界，让真实一次复习只更新一次状态、只追加一次历史；不能同时调用两条会重复记录的服务路径。
2. 独立 sidecar 记录 `AffectObservation`、`LearningContext`、`InterventionEvent`、`ProbeOutcome`。情绪观测、休息建议、图谱浏览、解释阅读不能伪装成 `ReviewTag`。
3. 冻结个人化 FSRS 的权重版本；或事先注册同一滚动训练程序并保证两条件一致。不能一边改变情绪策略一边不受控地重训基础 FSRS。
4. 以用户本地学习日界推进现有调度器，以 UTC/单调时间记录媒体与策略事件；保留两者转换，防止跨时区或午夜把同日/跨日混淆。

## 4. 数据与时间契约

### 4.1 每次复习的阶段

`t_queue`（候选队列冻结）→ `t_show`（显示题干）→ `t_answer_start` → `t_submit`（提交并封存原始作答）→ `t_reveal`（显示答案/反馈）→ `t_grade`（确定真实 grade，更新记忆）→ `t_next`。

真实客户端可能先 reveal 后 grade，应记录实际时间，不强制伪造上述顺序；关键约束是预测所用的所有媒体片段与特征均早于该预测对应的目标时刻。任何方案若改变作答过程，例如提示，必须有独立事件。

观测有三种明确用途：

- **会话策略输入**：只读该策略决策时刻之前已完成推理的片段。返回晚了不能回溯干预过去；可用于之后的决策，且遵守新鲜度窗口。
- **当前作答预测输入**：仅用题目提交/评分之前的媒体。禁止看到 reveal、正确性标识、评分按钮、答案讲解后的反应。口头答案的语义若进入模型，必须另外声明为“作答内容预测”，不能把性能提升归因于情绪。
- **下一次复习预测输入**：上一轮完整事件可用，但严格早于下一轮；上一轮答错反应本身可能是 grade 代理，所以仍须行为特征消融。未来间隔、未来是否回来、下一次 reveal 均不能用于训练时的历史特征。

每条观测至少记录：observationId、reviewEventId/sessionId、captureStart/captureEnd、inferenceFinishedAt、sourcePhase、输入模态 mask、设备/模型/权重/提示词版本、输入质量、原始输出与解析状态、校准版本、处理状态。模型若只有自由文本输出，概率字段设为缺失，不填写臆造的 confidence。用户手动报告疲劳或困惑另记 selfReport，不能覆盖模型原始结果。

输入文本只包括用户授权的自然口语转写或感受描述，默认排除标准答案、自动判分、题目解释和屏幕 OCR。保留一种更严格的 `A/V only` 比较，以识别文本是否携带答案内容。每个对比条件使用相同时间窗口。

### 4.2 隐私与存储

个人本地开关默认关闭采集；启用时明确说明相机/麦克风和用途，可随时停止。默认不长期保留原始音视频，研究阶段确需复核的片段必须单独同意并有删除期限。所有显式媒体、缓存、下载、模型权重、日志、推理临时文件、实验输出均指定到 D 盘研究目录/用户选定 D 盘数据目录；未来运行 Python 等工具时同时覆盖 TEMP、TMP、HF_HOME、HUGGINGFACE_HUB_CACHE、TORCH_HOME、XDG_CACHE_HOME 等路径，不能仅改输出文件夹。不能声称仅配置应用路径就能约束操作系统分页、驱动和系统审计日志。

这轮只写研究文档，没有下载权重、录制媒体或执行模型。

## 5. 首期融合：情境感知会话策略

### 5.1 候选集合和不可破坏条件

FSRS 先生成应复习集合与风险：`r_i = R_i(now)`。先按到期/逾期规则分组，再在相近到期风险组内部考虑情境；不得用笑脸把逾期项目移出队列、把预计记得好当作真实记得好、对某类情绪无限期延期。

可选动作限定为：`NoAction`、`OfferShortBreak`、`OfferSelfReport`、`OfferAfterAnswerExplanation`、`ReorderWithinRiskBand`。动作以建议呈现，用户接受/拒绝单独记录。用户主动休息/结束始终优先；任何测试条件都不能阻止主动停止。

建议规则采用非诊断语言：“需要短暂休息吗？”、“要看看这个知识点的先修概念吗？” 不向用户显示“你是悲伤/焦虑，所以记忆下降”等未验证推断。手动报告疲劳支持休息建议；仅有摄像头推断而无个人场景验证时只做 shadow 记录。

默认 `NoAction`。门控函数为：

`eligible = consent && fresh && validSchema && qualityPass && calibratedForThisMask && notInCooldown`。

提案初始工程约束：来自决策前不超过 60 秒的观测，至少两个相隔的有效短窗呈现一致证据后才考虑建议；建议间隔至少 10 分钟；每次会话最多 2 次额外主动提示。所有数字须在可用性试验中调整并版本化，它们不是生理阈值。严重积压时优先提醒调整会话预算，不能静默推后复习日期。

### 5.2 与知识图谱相接

困惑证据可以提高“答题后提供先修知识解释”的候选优先级，但选取知识节点必须基于经过核验的题目-知识点和 prerequisite 边。情绪不能证明某概念未掌握，也不能触发整片邻居概念遗忘或自动降低 mastery。

提示发生在作答前时，该次结果必须标 `assisted=true`，不能作为无辅助检索的评估标签；如果提示透露了答案，应记录一次不同性质的学习暴露，不能作为标准独立检索成功。图谱解释、读答案都可能改变记忆，必须记录 exposure；不能把这些学习机会完全忽略又声称严格拟合纯复习历史。首期干预优先安排在正常评分之后，不为解释浏览伪造 FSRS grade。

## 6. 模型研究：先预测增量，再考虑改间隔

### 6.1 固定基础模型

记 `F_w(S_i,D_i,g_i,Δ_i)` 为本地 FSRS-6 状态更新，

`R_0(t | S_i) = (1 + f*t/S_i)^(-w20)`，`f = 0.9^(-1/w20) - 1`。

基础模型根据真实 grade 推进；旧模型版本、权重、日界语义都冻结。保留纯 FSRS-6 对照。不要在这次融合项目中顺便升级到 FSRS-7。

### 6.2 阶段 A：只做 shadow 的条件回忆预测

`logit p_i = logit(clamp(R_0(Δ_i),ε,1-ε)) + β0 + β_b^T b_i + β_e^T z_i`。

`b_i` 为已观测的行为和情境混杂因素：此前正确率、历史间隔、历史响应时间、会话长度、题型/知识域、是否辅助、时间段；所有值必须预测时可得。`z_i` 是少量经过个人场景验证的情境特征与模态缺失标识，不直接使用高维 LLaMA embedding。

先拟合严格正则化的线性/logistic 残差，冻结 FSRS 参数，不联合训练几十到数百万额外参数。固定 offset 能衡量超出 FSRS 的增量；必须同时比较 `FSRS+行为`，避免把已由速度或疲劳时间解释的收益归到多模态。可以用 `z_i = confidenceGate * centeredFeature`，但只在存在可校准概率时使用 confidence；其余情况下只保留类别/文本解析特征和缺失值。

当前题提交前的 `z_i` 只能预测该时刻的表现，不保证是长期记忆。当前次回答的完整文本或揭示后的表情禁入此目标。此模型不调用 inverse interval；因为未来情绪未知，不能用当前状态假定数天后仍相同。

### 6.3 阶段 B：有门槛的稳定性残差，默认不启用

只有下一次跨日回忆的时序测试明显获益，才研究上一轮学习情境对记忆保持的影响：

`S_i^base,D_i^base = F_w(...)`

`δ_i = clip(γ^T z_i, -c, c)`

`S_i^eff = clip(S_i^base * exp(δ_i), S_min, S_max)`

`R_eff(t) = R_0(t | S_i^eff)`。

`z_i` 只取上次学习结束前已观测的信息；不能塞入未来复习时的情绪。以 `γ=0` 和强零中心正则作为起点。`D` 保持基础值，参数数量小且可解释。每次历史状态从相同的基础路径独立重放，不把残差反复叠乘进下一轮基础 S，否则会产生隐式累积偏置。

第一轮启用试验的提案边界：`c=log(1.10)`，即单轮 effective S 的变化最多约 ±10%（乘法下界为 1/1.1）；记录未裁剪值和触及边界频率。此上限只是试验控制，不证明安全或最优。计算所得间隔受相同最大间隔与积压规则约束。真实部署仍须单独随机对照验证，不能因为预测曲线更准就宣称学习更好。

该写法使固定历史下 `R_eff(t)` 随 t 单调下降，可回退到 γ=0；比自由神经网络直接输出天数更可审计。它依然只是待检验的参数化假设：情绪影响可能短暂、非单调或与内容相关，若数据不支持就不采用。

## 7. 个人验证协议

### 7.1 冻结问题和结果指标

H1：在当前自然复习条件下，模型提供的情境提示与本人报告之间存在可用的对齐，且有足够覆盖率。

H2：在预测时可得的历史与行为之外，多模态观测能降低下一次跨日无辅助回忆的概率损失；比较对象必须包含 `FSRS+行为`。

H3：在保持 FSRS 基础调度一致时，情境感知会话建议能改善个人的会话体验或完成度，同时延迟记忆不劣化。

H4（远期）：受约束稳定性残差的调度，在同等学习预算下改善延迟回忆，或在回忆不劣化时减少负担。

H1 不推出 H2，H2 不推出 H3/H4；拒绝把识别 F1、即时正确率、点击率或情绪变得愉快作为长期学习效果证明。

主要长期结果：预先抽定题目的 7 日无提示检索，30 日作为关键次要结果；实际测验延迟、期间所有复习/读答案/提示机会、反应时间和缺席均记录。测试可在预注册窗口内，例如 7±1 天、30±3 天；超窗不能偷偷当准时测试。固定 probe 本身也是一次检索，应在评分封存后正常进入记忆历史。

对个人日常使用，优先从两条件都相同且与策略独立的抽样规则抽取 probe，测验前不显示答案。期间正常复习允许继续，研究估计的是“完整策略下的延迟表现”；不能解释成无再学习的遗忘率。若另做无再学习保持实验，须另设可接受的小型实验题池并禁止中间暴露，不能混合两种 estimand。

会话短期指标：主动中止、复习完成率、总学习时间（包括休息/解释）、提示接受率、主动干预打扰感。按预先选定目标例如“在保持回忆的条件下提高完成率”判断，不任意多指标挑显著者。

### 7.2 顺序阶段与单人设计

**阶段 0，可行性与观察**：建议 14 天自然复习，只采集获得同意的数据，不改变调度。对 50–100 个分散在不同日、光照、模态和题型的短窗做可选本人状态报告；这只是可行性样本，不能据此保证所有情绪类别校准。标签以“疲劳程度/是否需要休息/困惑程度”等学习情境为主，同时保留原情绪类别；映射另标为新的个人小模型，不宣称原模型天生支持 fatigue/confusion/boredom。

本人自报是主观体验参照，不是绝对真值；视频观察者的表情标签也不能替代本人情绪。收集时间应固定/稀疏，避免标签询问本身成为高频干预。标注查看时隐藏模型输出与正确答案，防止确认偏差。

**阶段 1，至少覆盖多个星期的单人随机可行性实验**：建议 8 周加最后一次试验后的 30 天随访，日程只是预算提案。以会话为主要随机单位，在预先定义的合格会话内随机提供“情境感知建议开启”或“相同采集、建议关闭”，分配概率 1/2；按时间段/工作日做小区组平衡。会话级随机化可减少一次休息影响后续题目造成的跨题污染。建议版本、图谱状态、基础 FSRS 参数固定。

如果只研究一条短期建议，也可在合格决策点微随机“提出建议/不提出建议”，设置冷却和不重叠的 proximal outcome 窗口，记录每次 eligibility、真实分配概率、action、acceptance；这种 MRT 主要评估短期直接效果，长期总策略效应另需会话/天级随机化。不能把每次随机化都当独立受试者。

阶段 1 的主比较评估整个感知建议策略；要声称 Emotion-LLaMA 本身有价值，下一轮必须比较相同提示频率/动作规则的“只用行为+手动状态”与“行为+多模态”版本。不能用“有任何关怀提醒”对“完全无提醒”结果直接证明多模态有效。

**阶段 2，只有数据支持才试调度残差**：在新时间段、新 probe 集上单独比较 base FSRS 与受约束 residual；不用阶段 1 已反复调参的数据确认效果。若单人的信息量不足，应结论为暂不可确认，维持 base FSRS。若目标变成面向其他人发布，需多人、跨个体外部验证。

### 7.3 统计方案和证据门槛

- 预测模型用 expanding/rolling 时间切分，保留最终一段完全未见的日期；标准化、缺失填补、标签映射、阈值、校准、超参都只在训练/验证期拟合。按完整会话切分，不随机拆同一会话的临近题。
- 同一卡在未来测试出现允许，因为目标是个人已有卡的未来预测；另做按知识主题留出可检验新主题迁移。不要把这两种目标混为“泛化”。
- 多人后续研究另设完全未见用户集合；任何一个人的训练数据不能泄漏到未见用户测试。
- 模型损失用 held-out 未加正则的 log loss，附 Brier、校准图、分箱误差、AUC。训练目标的正则化 loss 和 `FitResult.Improved` 不能充当预测证据。
- 单人置信区间用按日/连续周的区组 bootstrap 或保持随机化区组的 randomization inference；有携带效应时扩大区组并做敏感性分析。不能对几十张相近卡使用 iid bootstrap 并假装有几十个独立用户。日级重复也要检查趋势、自相关和任务域变化。
- 意向处理主分析按随机分配条件统计，拒绝建议者仍留在分配组；按接受程度分析仅作辅助。缺席/退出单独报告，并做缺失结果的保守界限和模式敏感性分析。
- 后续若做 off-policy 评估，需记录并保证策略的行动概率有重叠；没有探索概率的确定性日志不能识别从未发生动作的效果。重要性加权/DR 方法也不能消除未观测混杂或缺乏支持。[S12]

拟采用的门槛（项目决策阈值，不是文献标准）：

1. **观测可用**：在对应模态和本人自然场景的独立时间段上，主动建议触发 precision 的 95% 下界达到 0.80；同时报告 recall、coverage、总触发率与每会话误提示。数据不足计算稳定界限时仅 shadow/手动，不降低要求来“通过”。自由文本概率未校准时用经人工核验的触发规则/小校准模型，不能直接使用自述信心。
2. **预测增量**：`FSRS+行为+多模态` 对 `FSRS+行为` 的跨日 held-out log loss 相对降低至少 1%，按日/周成组的 95% 区间支持改善；主要校准误差不恶化。1% 仅是事先选定的最小实用差异，应同时报告绝对差和置信区间。通过才有理由进入残差调度研究。
3. **个人会话策略采纳**：7 日回忆差的 95% 下界高于 -3 个百分点（非劣界限），预注册的体验/完成目标改善，包含休息在内的时间成本不超预算。30 日效果及失访率单独公布。未达到精度则继续保持可选模式，不宣称证明有效。
4. **自动改间隔**：还须单独随机化得到长期收益或同保持率更低负担的证据。不能仅凭门槛 2 开启。

功效不能由“收集 1000 条数据”保证。仅作量级演示：若比较 90% 和 92% 的独立二项成功率，双侧 α=.05、power=.80 的简化等样本近似每组约 `2*.91*.09*(1.96+.84)^2/.02^2 ≈ 3210` 条结果，总计约 6420；这不包含聚类、自相关、失访和多指标。该式不是本项目实际功效分析。每会话 m 条且 ICC=ρ 时常用近似 design effect 为 `1+(m-1)ρ`，实际设计应从 pilot 的日/会话相关、合格比例、失访与 carryover 进行模拟。单人的数千条卡片记录仍不能提供对其他用户的总体推断。[S11]

## 8. 最小消融矩阵

| 编号 | 输入/决策 | 回答的问题 |
|---|---|---|
| B0 | 冻结 FSRS-6 | 基础表现 |
| B1 | FSRS + 已知行为/时长/题型 | 简单便宜的上下文是否已足够 |
| B2 | B1 + 稀疏本人状态报告 | 主观情境增量 |
| E-A | B1 + 音频分支 | 声音是否有额外信息 |
| E-V | B1 + 视频分支 | 图像是否有额外信息 |
| E-T | B1 + 授权自然语言，排除标准答案 | 文本情境增量，检查语义作答泄漏 |
| E-AV/AVT | B1 + 可运行的多模态组合 | 融合比单模态是否更好 |
| P-shuffle | 多模态特征在训练期按日/题型受控置乱 | 是否只学到会话/时间代理；仅作负对照 |
| P-missing | 自然缺失和受控掉模态 | coverage/失效回退是否稳健 |
| I0/I1/I2 | 相同采集下无建议 / 行为建议 / 多模态建议 | 建议本身与模型增量分开 |
| M0/M1 | base FSRS / 受限稳定性残差 | 间隔改变的实际因果收益，远期试验 |

以上单模态消融只在官方运行路径或经验证适配器确实支持对应输入时实施。不得向强制要求音频的原实现塞全零音频并称为“官方视频单模态”；缺模态时应明确 adapter failure/unsupported，回退基线。一个人的稀疏数据不适合同时拟合所有条件：顺序筛选，再锁定一个主比较，其他结果标探索性并控制多重比较。

## 9. 模态缺失、偏差和漂移

输出状态至少区分 `ok`、`unsupported_modality`、`low_quality`、`stale`、`parse_error`、`timeout`、`service_unavailable`、`user_disabled`。只有 ok 且满足门控才进策略；其余回到基础 FSRS/手动状态，并保留原因。默认缺失不等于 neutral；无脸可能是转头看笔记，无语音可能是默读，不应变成负面情绪标签。

模态 mask 应作为评估分层，而不是简单删除全部缺失行。掉模态可能由学习困难、主动退出或设备变化引起，缺失不随机；报告 missingness 与作答/退出的关系，用受控缺失压力试验辅助判断，不由此证明真实缺失无偏。

每人基线、光照、眼镜、口音、阅读习惯、说话方式、疾病/障碍等会改变外部行为。个人场景优先检查本人跨日期和环境稳定性；未来多人发布再用获得同意的人群分层检查误触发、漏触发、coverage和效益，不能从一个人的结果宣布无偏。不要用猜测的年龄/性别/族群作强制推断来“纠正情绪”。

固定模型每月或摄像头/麦克风/提示词/模型更新后检查漂移；重新校准必须只用新的训练窗，然后另留未来验证窗。无法维持触发校准则降级 shadow。通过手动纠正收集的样本要标记为主动选择样本，避免只看到错例造成训练分布扭曲。

## 10. 可执行里程碑与停止条件

1. 完成事件契约、时间边界与原始数据目录设计；列清哪些流程产生真实 grade、哪些仅是暴露，不修改现有 SDK。
2. 独立研究运行器先检查权重获取权限、缓存目录、输入/输出 schema、单个短片推理时延/峰值内存/缺失音轨结果。所有缓存 D 盘。当前硬件无法完成时明确记录失败，不拿模型官网 demo 的运行速度冒充本地测量。
3. 个人 14 天可行性采样；达到观测可信度才允许可选建议。
4. 先比较 simple behavior/self-report 与 multimodal 的离线增量；无增量则停在可选辅助/研究记录。
5. 锁定版本后做会话随机试验；置信区间不够窄，结论写不确定，不写有效。
6. 只有 H2 与实际策略收益都支持时，再预算稳定性残差试验；不联合训练 Emotion-LLaMA 与 FSRS，不做强化学习直接输出间隔。

如果多模态推理不能在本地预算内运行、无法取得合规权重、自然场景触发不可靠、比简单行为无增量、或长期结果出现明确劣化，则默认恢复纯 FSRS 与用户自助休息/解释。该结果也是有效研究结论。
