# Noto CJK fonts

ReciteHelper bundles unmodified Noto Sans CJK SC (Regular, Medium and Bold) and Noto Serif CJK SC (Regular and Bold) as embedded WPF resources.

Source: https://github.com/notofonts/noto-cjk

Source revision: f8d157532fbfaeda587e826d4cd5b21a49186f7c

Font paths: `Sans/OTF/SimplifiedChinese/` and `Serif/OTF/SimplifiedChinese/`.

The fonts are distributed under the SIL Open Font License, Version 1.1. Their embedded copyright metadata is unchanged. The upstream license texts are retained in `Sans-LICENSE.txt` and `Serif-LICENSE.txt` alongside this notice.
